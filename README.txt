MEDICORE
Integrated Hospital Management System
"Smarter Management. Better Care."

Copy this folder to C:\xampp\htdocs\
Start Apache and MySQL in XAMPP.
Open phpMyAdmin and import database.sql.
Then visit http://localhost/hospital_management_system/

Included working module: Patient registration, listing, editing and deletion.
Prepared folders for Doctors, Appointments, Medical Records, Laboratory, Pharmacy, Admissions and Billing.
